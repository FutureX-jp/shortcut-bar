01 — Work

探す時間を、
減らす。

タスクバー、スタートメニュー、電卓、天気サイト。行ったり来たりしていた場所を、いつも見えている画面の端にまとめます。

01

並べて、1クリックで開く

アプリ・ファイル・フォルダ・URLを1枚のタイルに。アイコンは実物から自動で拾います。

  • ファイルやフォルダはバーへドラッグするだけ
  • 仕事用・在宅用など「作業セット」を丸ごと切替
02

開いている窓が、いつも見える

起動中のウィンドウが縦に並び、クリックで前面へ。マウスを乗せると中身がライブで浮かびます。

  • 行の📷でその窓だけをスクショ
  • 行を放り投げると左右半分・最大化にスナップ
03

1本の欄で、検索も計算も

アプリ・フォルダ・Webを横断検索。式を打てば電卓、単位を打てば換算になります。

  • Ctrl+Alt+Space でどこからでも呼び出し
  • クリップボード履歴・付箋もバーの中に
04

設備屋の単位、そのまま

呼び径 B⇔A の早見表、圧力・流量・面積・熱量の換算。設備・建築の現場で毎日使う数字を入れました。

  • 1/2B ⇔ 15A・kPa ⇔ mmAq・m³/h ⇔ L/min
  • 坪 ⇔ ㎡・kW ⇔ kcal/h

08 — Start

はじめかたは、
3ステップ。

インストーラーはありません。exe を開くだけで、画面の端に住みつきます。

  1. ダウンロードして開く

    ShortcutBar.exe をダブルクリック。画面の端に小さなバーが現れます。SmartScreen が出たら「詳細情報」→「実行」。

  2. よく使うものを登録

    バーを右クリック →「📌ショートカットを追加」。アプリ名を打つと候補が出て、名前もアイコンも自動で入ります。

  3. タスクバーの代わりに

    ⚙設定 → 配置 →「画面端に固定」。Windows のタスクバーを自動で隠す設定にすれば、画面が広々。

迷ったら、まずバーを右クリック。使える機能がメニューにまとまっています。

09 — FAQ

よくある質問

Macやスマホで使えますか？

いいえ。Windows 10 / 11 専用です。Mac・Linux・スマートフォン（iPhone / Android）では動きません。

本当に無料で使えますか？

はい。標準機能は無料で、期限もありません。天気・雨雲レーダーも無料です。レトロ携帯機風テーマのみ、無料版では5日間の体験期間があります（ミニマル・クラシックはずっと無料）。

インストールは必要ですか？

不要です。exe をダウンロードしてダブルクリックするだけ。必要な実行ライブラリは同梱済みです。設定はユーザーフォルダの中の1ファイルだけなので、いらなくなったら消すだけで消えます。

SmartScreenの警告が出ます

個人開発でコード署名をしていないために出る表示です。「詳細情報」→「実行」で起動できます。

おすすめの使い方は？

作者のおすすめは、Windows 標準のタスクバーを隠して、ショートカットバーをタスクバー代わりにする使い方です。

  1. バーの ⚙設定 → 配置 →「画面端に固定」で好きな画面端にドッキング
  2. Windows の 設定 → 個人用設定 → タスクバー →「タスクバーを自動的に隠す」をON
天気のデータはどこから？

日本国内は気象庁の公開データ（予報・警報・地震・雨雲ナウキャスト）、雨雲レーダーの地図は国土地理院のタイルです。海外の地点は Open-Meteo を使います。

PCを買い替えたらキーは？

同じメールアドレスとキーでそのまま再認証できます。回数制限はありません。

割引はありますか？

あります。アプリ内の 🚚 トラックシミュレーター（無料）で貯めたコインを、🔧 ガレージの「券」の棚で Pro版の割引コードに換えられます。20%OFF（¥784）は100,000コイン、40%OFF（¥588）は250,000コイン。各コード先着30名・2026年12月10日まで。コインは1日でおよそ5,000貯まります（作者の実測）。

自分のソフトやお店の広告を出せますか？

出せます。トラックシミュレーターの高速道路ぞいの看板に、横長の画像＋https のリンク先（または文字だけ）を載せられます。いまは掲載料無料・最大12枚。看板枠からどうぞ。

支払い方法は？

Stripe の購入ページで決済します。使える支払い方法は購入ページに表示されます。カード情報が開発者に渡ることはありません。

データは外に送られますか？

使用状況の共有（テレメトリ）は、同意した場合だけ匿名で送ります。ファイル名・パス・クリップボード・メモの中身・ウィンドウのタイトルは送りません。くわしくはプライバシーポリシーへ。
