1. ランチャーの基本

画面の端に常駐する細いバー。よく使うものを並べて、1クリックで開きます。

⚡ショートカットを並べる無料

アプリ・ファイル・フォルダ・URL・Windowsの設定画面まで、なんでも1枚のタイルにできます。アイコンは実物から自動で拾うので、見た目のちぐはぐがありません。

  • ドラッグ＆ドロップで並び替え
  • アイコンは実アイコン／絵文字／好きな画像から選択
  • 名前は自由に変更可・長い名前は自動で省略
  • グループ分け（フォルダのようにまとめる）に対応
追加のしかた：バーを右クリック →「＋ショートカットを追加」。または、ファイルやフォルダをバーにドラッグ＆ドロップするだけ。

🧩作業セットの切り替え無料

「今のセットを保存」で、並べたショートカット一式に名前を付けて保存できます。仕事用・ゲーム用・在宅用を、ワンクリックで入れ替え。

  • 前面のアプリに応じてセットを自動で切り替えることも可能

📌タスクバーの代わりに使う無料

画面の端に固定（AppBar）すると、他のウィンドウを最大化してもバーの上に重なりません。Windows標準のタスクバーを隠して、こちらを主役にできます。

  • 上下左右どこにでも固定可・自動で隠す設定も
  • 半透明度の調整、マウスが離れたら薄くなる設定も

2. フォルダのショートカット

よく開くフォルダこそ、1クリックで。

📁フォルダを選ぶだけで登録無料v1.7.53

追加画面の「📁 フォルダを選ぶ…」から選ぶだけ。名前・場所・アイコンが自動で入ります。フォルダの見た目を変えている場合は、その絵柄のまま登録されます。

  • 検索欄に「ダウン」と打てばダウンロードフォルダが候補に出る
  • 「C:\」と打てばドライブ直下のフォルダが並ぶ
  • 右クリック →「📌 クイック追加」→「フォルダ…」が最短
  • 隠しフォルダやシステムフォルダは候補に混ざりません

🗂開いているフォルダをそのままピン留め無料v1.7.54

エクスプローラーで開いているフォルダを、バーの「起動中」一覧から右クリック →「📌 ピン留め」でそのまま登録できます。今まさに見ている場所が登録されるので、パスを探す必要がありません。

  • タブを複数開いているときは、どのフォルダを登録するか選べます
  • 同じ名前のフォルダが並んでも、親の場所を表示するので迷いません
  • 「ホーム」「PC」をピン留めすると、その名前のボタンになります

3. 検索・電卓・単位換算

バーの上の1本の入力欄が、いろいろな顔になります。

🔎横断検索無料

登録したショートカット・インストール済みアプリ・フォルダ・Web検索を、1つの欄からまとめて呼び出せます。

  • 名前の一部を打つと候補が下に出る → 矢印キーで選んで Enter
  • 「example.com」はそのまま開く／それ以外の語はWeb検索
  • 「天気」「換算」などツール名を打つと、その画面が開く

🧮電卓無料

検索欄に 3980*1.1 と打つと = 4378。Enter で結果をコピーします。電卓アプリを開く手間がありません。

📐単位換算パネル無料

設備・建築の現場でよく使う単位をまとめました。検索欄に直接打っても、パネルを開いても使えます。

  • 呼び径 B ⇔ A の早見表（1/2B ⇔ 15A など）。セルをクリックでコピー
  • 圧力（kPa / MPa / mmAq / kgf/cm²）
  • 流量・面積（㎡ ⇔ 畳 ⇔ 坪）・熱量・長さ・重さ

⌨️どこからでも呼び出し無料

Ctrl + Alt + Space で、他のアプリを操作中でもバーを前面に呼び出して、そのまま検索欄に打てます。

  • ホットキーは設定で変更・無効化できます

4. ウィンドウの操作

開いている窓の一覧が、常にバーの中にあります。

🪟起動中アプリ一覧無料

今開いているウィンドウが縦に並びます。クリックで前面へ、もう一度で最小化。同じアプリの複数の窓はまとまって表示され、展開もできます。

  • 右クリックで 前面 / 最大化 / 最小化 / 元のサイズ / 閉じる
  • 各行の 📷 でその窓だけをスクリーンショット保存
  • 右クリック →「📌 ピン留め」でショートカットに追加

🥏窓投げ・重力モード無料

一覧の行をつかんで放り投げると、投げた方向にウィンドウがスナップします。左半分・右半分・最大化を、マウスひと振りで。

  • 重力モード：アイコンが物理演算で落ちて跳ねる、ちょっとした遊び

▦全ウィンドウ一覧無料

開いている窓を、ライブサムネイルのタイルで一覧表示。クリックで切り替えます。Alt+Tab より探しやすい場面があります。

📷スクリーンショット無料

ウィンドウ単位で保存します。保存先は Windows 標準の ピクチャ ＞ Screenshots なので、他のアプリからもすぐ見つかります。

5. 覗き窓と PiP 監視

「切り替えずに、ちらっと見たい」を叶える機能です。

👁覗き窓（ライブプレビュー）無料

起動中の行にマウスを乗せるだけで、その窓の今の中身が小さく浮かびます。静止画ではなくライブ映像です。

📺PiP監視（ミニ表示で見張る）Pro

任意のウィンドウを、常に手前の小窓でライブ表示します。ビルドの進捗・監視カメラ・チャット・長い処理の進み具合を、作業しながら見張れます。

  • 小窓の中をそのまま操作できます（クリック・スクロール）
  • 小窓から文字も打てます。打っている間も相手の窓は前に出てきません
  • 文字が打てる場所を押すと、黄色い枠と「ここに打てます」が出ます
  • 大きさは自由・常に最前面・画面からはみ出さない位置に開きます
使いかた：起動中の行を右クリック →「📺 ミニ表示で監視（PiP）」。
※一部のアプリ（Brave など）は、アプリ側の設定で外部からの操作が切られています。その場合は理由と直し方を画面に表示します。

6. 天気・防災

数値の出どころは気象庁。ブラウザを開かずに、傘の判断ができます。

🌤今の天気と予報無料

  • 気温・湿度・風・体感（現在値はアメダスの実測）
  • 今後24時間の降水確率グラフ
  • 時間ごとの気温グラフ（最高＝赤／最低＝青）
  • 時間ごとの風向き（矢印）と風速
  • 週間予報（気象庁の公式発表に準拠）

🌧雨雲レーダー無料

直近の実況に加えて60分先までの予報をアニメーション再生。コマ送りと拡大縮小に対応しているので、「あと何分で降るか」が読めます。

⚠️警報・注意報・地震無料

  • 注意報＝黄／警報＝赤／特別警報＝紫 で色分け表示
  • 最近の地震情報もあわせて表示
  • 雨雲が近づくと、相棒が「傘の準備を！」と知らせます
地域の設定：現在地の自動取得のほか、都道府県 → 市区町村を選ぶだけ。地名を手で入力する必要はありません。

7. 時計と背景アニメ

ただの時計にしないための、小さなこだわり。

🕒その日の空が背景になる時計無料

時計の背景に、その時間・その天気の空をアニメーションで描きます。朝焼け、日中の雲、夕暮れ、そして夜は星と月。

  • 夜は季節ごとの星座が浮かびます
  • 雨・雪の日はちゃんと降ります
  • 風が強い日は、流れる線が増えて速くなります
  • アナログ時計／デジタル時計の切り替え可

8. 小さな便利道具

「これだけのために別アプリを入れたくない」ものを詰めました。

📋クリップボード履歴無料

コピーした文字がバーに残ります。クリックで再コピー。よく使う文はピン留めして常に先頭へ。

🗒付箋マグネット無料

画面に貼りっぱなしにできる小さなメモ。バーの端に磁石のようにくっつきます。

📊今日の作業ログ無料

どのアプリをどれくらい使ったかを、その日ぶんだけ記録して表示します。記録はあなたのパソコンの中だけで、どこにも送信しません。

🕘最近のウィンドウ無料

さっきまで開いていた窓に戻れます。閉じてしまったフォルダを探し直す手間が減ります。

9. シークレットメモ

見せたくないものを、見せずに使う。

🔑暗号化メモPro

パスワードや番号など、人に見られたくない短いメモを暗号化して保存します。中身は伏せ字で表示され、クリックするとクリップボードにコピーされます。

  • コピーした内容は30秒後に自動で消去されます
  • 保存先はあなたのパソコンの中だけ。クラウドには一切送りません
  • タスクバーやAlt+Tabにも中身が出ない作りです

10. 着せ替えと相棒

道具は、気に入った見た目のほうが長く使えます。

🎨3つのテーマ無料

  • ミニマル：余白のある今どきの見た目
  • クラシック（青）：懐かしのあの雰囲気。スタートメニューまで再現
  • レトロ携帯機風：十字キーで操作するホーム画面

🖼壁紙モードPro

好きな画像を1枚まるごとバーの背景に。スマホのホーム画面のように、アイコンも時計も写真の上に静かに並びます。

  • 表示範囲はプレビューをドラッグして選ぶだけ
  • 文字色・書体もカスタム可。背景の明るさに応じて自動で読みやすく調整
  • 壁紙の上でもクリック・ドラッグ・スクショなど全機能そのまま

🐬デスクトップの相棒無料

画面の中を小さな相棒がのんびり歩きます。標準はイルカの「フィン」、きせかえで作者の愛猫「めめ」にも。

  • ファイルをドラッグして渡すとゴミ箱へ運んでくれる
  • 雨雲が近づくと傘の準備を教えてくれる
  • ダブルクリックでなでなで・放置すると寝る・毎時の時報
  • リマインダーとポモドーロタイマー

11. スタートメニュー

クラシックテーマでは、あの青いスタートメニューが戻ってきます。

🚀編集できるスタートメニュー無料

左にピン留めしたショートカット、右にシステム項目とツール。並び順も表示・非表示も自分で決められます。

  • システム欄：マイドキュメント／PC／コントロールパネル／Windows設定／Bluetooth／ネットワーク接続／プリンタとスキャナー／ファイル名を指定して実行／タスクマネージャー／電卓 など16項目から選択
  • ツール欄：天気／単位換算／全ウィンドウ一覧／重力モード／アシスタント／今日の作業ログ／今のセットを保存／シークレットメモ／ショートカット追加／バーの設定／使い方ツアー
  • 「すべてのプログラム」は実際にインストール済みの項目をカスケード表示
  • v1.7.54 左のピン留めは、ウィンドウが縦に伸びない範囲でできるだけ全部表示します（以前は10件まででした）

12. 設定・更新・プライバシー

安心して常駐させておけることを大事にしています。

⚙設定無料

表示する項目、テーマ、各機能のON/OFF、透明度、固定位置などをまとめて変更できます。項目は分類されているので、目当ての設定にすぐ辿り着けます。

🌈自動アップデート無料

新しいバージョンが出ると、ヘッダーの目玉が虹色になってお知らせします。クリックすれば更新は自動。失敗しても前のバージョンへ自動で戻ります。

📦インストール不要無料

exeファイル1つで動きます。レジストリを汚しません。設定はあなたのユーザーフォルダの中の1ファイルだけなので、いらなくなったら消すだけで完全に消えます。

🔒プライバシー無料

使用状況の共有（テレメトリ）は同意した場合のみ送信されます。送るのは完全に匿名の利用状況だけです。

  • ファイル名・フォルダの場所・パソコン名・ユーザー名は送りません
  • クリップボードの中身・メモの中身・ウィンドウのタイトルも送りません
  • 作業ログはあなたのパソコンの中だけに保存されます
  • 同意はいつでも設定から取り消せます
詳しくは プライバシーポリシー をご覧ください。
