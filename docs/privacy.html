プライバシーポリシー

本ポリシーは、デスクトップアプリ「ショートカットバー」（以下「本アプリ」）および本サイトにおける情報の取り扱いを定めるものです。

1. 本アプリが外部へ送る情報（場面ごと）

本アプリは、下の表の場面以外で、利用者の情報を開発者へ送ることはありません。氏名・ファイルの中身・閲覧したURL・クリップボード・画面の内容は、どの場面でも自動では送りません。

場面送る条件送る内容
使用状況（テレメトリ）「匿名の使用データ提供」がONのときだけ。初回起動時に確認し、拒否しても全機能を使えます。設定からいつでも変更できます端末ごとにランダム生成した匿名ID、アプリの版、OSの種類と版、出来事の名前（起動・同意・Pro有効化など）、時刻。Pro有効化時のみライセンスキーの指紋（キーから計算した値の先頭10桁。指紋からキーやメールアドレスは復元できません）
操作が相手のアプリに届かなかったとき上と同じ同意がONのときだけ。同じ種類の失敗は1回だけ送ります相手アプリの実行ファイル名、ウィンドウと部品の種類を表す名前（クラス名）、失敗の理由。同じ内容はお使いのパソコンの一時フォルダ（sbar_pip_miss.log）にも記録します
作業ログの集計（v1.7.58〜）同意がONで、利用者が「集計を送る」を押し、表示された中身を見て「送る」を選んだときだけアプリ名・回数・秒数の集計値だけ。ウィンドウの題・ファイル名・パスは含まれません（含まれていた場合は送信を中止します）
フィードバック利用者が送信ボタンを押したとき（上の同意の設定に関係なく送ります）。送信すると、使用状況の提供がONになります（送信画面に表示しています。設定でいつでもOFFにできます）入力した本文（4,000字まで）、添付した画像とそのファイル名（任意）、不具合の再現用の環境情報（画面とバーの大きさ、表示倍率、テーマなどの表示設定、直近のエラーの文面）、匿名ID、版、OS
Pro版の認証プロダクトキーを入力して有効化したとき購入時のメールアドレス、プロダクトキー、匿名ID（同じキーを使う端末の数を数えるため）
更新の確認更新の自動確認がONのとき（初期状態はON。前回から2時間以上たった起動時）最新版の情報ファイルを取得するだけで、利用者の情報は送りません（取得先には通信に伴うIPアドレス等が届きます）

2. 利用する外部サービスと、そこに届く情報

本アプリと本サイトは、次の外部サービスを利用します。各サービスには、通信に伴ってIPアドレスやブラウザー・OSの種類などの技術情報が届きます。

サービス用途届く・保存される主な情報
Google（Apps Script・スプレッドシート・ドライブ・Gmail）使用状況・フィードバック・Pro認証の受け付けと保存、受信の通知1章の表の内容。フィードバックの画像は開発者のGoogleドライブに保存し、受信時に開発者宛てに通知メールが届きます
StripePro版の決済購入時に入力する情報。クレジットカード情報は開発者に渡りません
GitHub（Releases・Pages）本アプリの配布、更新情報の配信、本サイトの公開、アプリ内看板の内容の配信通信に伴う技術情報
Cloudflare Web Analytics本サイトの閲覧数の把握閲覧されたページ、参照元、ブラウザー・OSの種類、おおまかな国・地域。Cookie・ローカルストレージは使いません（Cloudflareの説明）
気象庁天気・警報・地震・津波・雨雲の表示表示する地域の指定、通信に伴う技術情報
Open-Meteo天気の取得、地名の検索天気を表示する地点の緯度経度、検索した地名、通信に伴う技術情報
国土地理院地図の表示表示範囲の地図タイルの指定、通信に伴う技術情報
OSRM（router.project-osrm.org）内蔵ゲーム「トラックシミュレーター」の道路経路ゲーム内の出発地・目的地の座標（利用者の現在地ではありません）

外部サービスの処理は、各サービスの契約と体制により、日本国外（米国など）で行われる場合があります。

3. パソコンの中だけに保存するもの

  • 設定と匿名ID: 本アプリの設定ファイルに保存します
  • 作業ログ（初期状態はOFF）: %USERPROFILE%\.shortcut_bar_worklog\ に、前面になった時刻・アプリ名・ウィンドウの題・無操作だった秒数を記録します。120日より古い日は自動で削除し、OFFにすれば記録は止まり、フォルダごと削除できます。この記録がそのまま送られることはありません

本アプリをアンインストールしたり、パソコン内のファイルを消したりしても、すでに送った情報は開発者側から自動では消えません。削除をご希望の場合は6章の窓口へご連絡ください。

4. 使い道と第三者提供

集めた情報は、不具合の調査、品質改善、Pro版の発行・再送・返金対応、お問い合わせ対応にだけ使います。第三者への提供・販売は行いません（決済・保存のために上記の外部サービスへ預ける場合と、法令に基づく場合を除きます）。

5. 保存期間と削除

使用状況・フィードバック・認証の記録は、削除のご依頼を受けるまで保存します。一定期間で自動的に削除する仕組みは現在ありません。ご依頼を受けた場合は、該当する記録を開発者のスプレッドシート・Googleドライブから削除します。ただし、Google側のごみ箱や通知メールなどに一定期間残る場合があります。

6. お問い合わせ・削除のご依頼

情報の確認・削除のご依頼、本ポリシーへのお問い合わせは、特定商取引法に基づく表記記載の連絡先までお願いします。使用状況の削除をご希望の場合は、アプリの版とおおよその利用時期をお知らせください。プロダクトキーやパスワードはメールに書かないでください。

7. 改定

情報の取り扱いを変えた場合は、このページを更新し、重要な変更はアプリ内または本サイトでお知らせします。
